# 아이콘 라이선스

`sets/` 폴더의 아이콘은 모두 상업적 사용·수정·재배포가 가능한 오픈 라이선스입니다.
결과물(PPTX·HWPX·DOCX·PDF·HTML)에 아이콘을 넣는 데 별도 표기는 필요 없지만,
아이콘 파일 자체를 다시 배포할 때는 각 폴더의 `LICENSE` 파일을 함께 두어야 합니다.

| 세트 | 라이선스 | 저작권 | 용도 |
|---|---|---|---|
| Lucide (`sets/lucide`) | ISC | Lucide Icons and Contributors | 기본 (슬라이드·문서·웹) |
| Tabler (`sets/tabler`) | MIT | Paweł Kuna | 예비 |
| Phosphor (`sets/phosphor`) | MIT | Phosphor Icons | 예비 |
| Bootstrap Icons (`sets/bootstrap-icons`) | MIT | The Bootstrap Authors | 예비 |
| Heroicons (`sets/heroicons`) | MIT | Tailwind Labs, Inc. | 예비 |

- `index.json`: 아이콘 이름 목록 (자동 생성. 지우면 다시 만들어짐)
- `_cache/`: 색을 입힌 PNG (자동 생성. 지워도 됨)
- `settings.json`: 문서 소제목 아이콘 켜기/끄기 (사이드바에서 설정)
